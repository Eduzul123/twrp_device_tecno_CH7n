## OrangeFox Recovery device tree for the Tecno Camon 18P (CH7n)

The Tecno Camon 18P (TECNO-CH7n - codenamed _"CH7n"_) is a mid-range smartphone from Tecno.

It was announced in October 2021 and released in December 2021.

## Device specifications

| Feature                        | Specification                                                                             |
| -----------------------------: | :---------------------------------------------------------------------------------------- |
| Chipset                        | MediaTek Helio G96 (MT6781)                                                                     |
| CPU                            | Octa-core (2x2.05 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55)                                   |
| GPU                            | Mali-G57 MC2                                                                                  |
| Memory                         | 8GB RAM (LPDDR4X)                                                             |
| Shipped OS                     | Android 11 (HIOS 8.0) Android 12 (HIOS 8.6)                                                                   |
| Storage                        | 128GB (UFS 2.2)                                                                   |
| SIM                            | Nano-SIM + Nano-SIM                                                                       |
| MicroSD                        | microSD microSDHC microSDXC                                                          |
| Battery                        | 5000 mAh (non-removable), 33W fast charge                                           |
| Dimensions                     | 76.67 x 168.86 x 8.77 mm                                               |
| Display                        | 1080 x 2460 pixels,6.8 inches, 60/90/120hz     |
